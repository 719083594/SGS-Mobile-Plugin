# 三国移动助手 · SanguoshaMobile-Plugin

面向 [三国杀移动版](https://www.sanguosha.cn/) 的原创插件，聚合移动版官网资料与官方「[三国咸话](https://xh.sanguosha.cn/web/2)」社区。仅支持移动版，不使用 OL、十周年、欢乐三国杀等版本接口。

0.1.0 已实现公开查询、真实三国咸话 APP 扫码协议、加密会话保存和本人资料查询协议。**尚未完成用户实扫及个人字段验收；官号游戏登录、华为渠道游戏登录仍未证实。** 社区授权、登记游戏 ID、取得某条本人数据是三个不同的状态，不会自动标成游戏渠道登录成功。

## 安装与配置

需要 Node.js 22.15 或更高版本。

```sh
git clone https://github.com/719083594/SanguoshaMobile-Plugin.git
cd SanguoshaMobile-Plugin
npm install --ignore-scripts
node cli.mjs init
npm test
node cli.mjs diagnose
```

CLI 示例中的 `123456789` 是示例 QQ 号，操作授权时替换为本人 QQ 号：

```sh
node cli.mjs command 123456789 "#三国帮助"
node cli.mjs command 123456789 "#三国资讯"
```

TRSS/云崽：将本目录安装到 Bot 的 `plugins/SanguoshaMobile-Plugin`，在插件目录执行安装、初始化，将 `config/local.json` 的 `adapter` 改为 `"yunzai"`，重启 Bot，再发送 `#三国帮助`。`orangejuice.plugin.json` 提供橙汁中文配置入口。`adapter: "none"` 只启用 CLI/独立 API，不向云崽注册命令。

初始化自动生成实例加密密钥。需要扫码和本人查询时，确认实例 `personalDataEnabled: true`；设为 `false` 停止创建授权、查询扫码状态和读取本人数据，仍允许退出已有授权。完整参数表与上线检查见 [功能与配置清单](docs/FEATURES.md)。修改适配器、前缀、超时或缓存后重启，使已创建的客户端与命令规则使用新配置。

## 本人扫码流程

1. 在官方三国咸话 APP 登录，并在 APP 内关联需要查询的三国杀移动版角色。
2. 私聊 Bot 发送 `#三国社区授权`，使用三国咸话 APP 的「扫一扫」扫描收到的二维码，在官方界面确认。插件本地生成 PNG，二维码内容不会交给第三方绘码服务；二维码不得转发。
3. 私聊发送 `#三国扫码状态`。只有官方返回凭证并通过本人社区资料接口验证后，插件才保存会话。待扫码、过期或验证失败都不会显示授权成功。
4. 逐项私聊查询本人资料并与 APP 核对。战绩模式：`0` 全部、`1` 排位、`2` 身份、`3` 国战、`4` 斗地主。官方返回未关联角色时，在官方 APP 处理，再重试。
5. 不再使用时发送 `#三国退出授权`。即使远程接口异常，插件也删除本人本地会话。APP 扫码协议尚无已核实的远程撤销接口；其他客户端会话应在官方 APP 管理。

可选 `#三国社区授权 微信` 使用新版社区微信扫码协议。此协议只接入已核实的社区资料、游戏概览、角色映射接口；当前 Bot 命令中仅 `#三国个人资料` 对应其游戏概览，其他丰富资料请优先使用默认 APP 扫码协议。两套协议不混用凭证。APP 二维码的 120 秒是官方前端轮询窗口；会话有效期以官方实际响应为准。

CLI 同样支持扫码与个人命令；二维码或过长的 JSON 保存到 `data/exports/`，终端输出实际文件路径。使用同一个本人 QQ 号查询状态，查看后自行删除私密文件。云崽过长数据通过好友文件发送；协议端不支持发送文件时会明确提示。

## 数据与隐私

会话按 QQ 号隔离，使用 AES-256-GCM 加密保存到 `data/sessions.enc.json`。密钥保存在 `config/local.json`；这两者均被 Git 忽略。密钥与加密文件应一起妥善保管，直接修改密钥会使旧会话无法解密。游戏身份文件和 CLI 导出也在被忽略的 `data/` 内。

插件不接收密码或验证码；本人结果递归过滤凭据、联系方式、实名及设备标识等字段。个人消息只允许私聊。API 返回官方来源，不将公开武将皮肤图当作本人拥有皮肤，也不将社区武将收藏当作拥有武将。本人查询按官方实际结构返回 JSON，字段完整性仍需本人实扫验收。

独立调用通过 `api.mjs` 导出的 `MobilePublicClient`、`CommunityAuthClient`、`SanguoshaMobile` 使用。公开数据模块无需登录；独立 API 使用者负责保存自己的会话，不能向其他用户公开授权对象。

准确命令、已接入接口、待验收项目见 [功能清单](docs/FEATURES.md)，协议证据与匿名实测见 [API 审计](docs/API-AUDIT.md)。原创代码为 GPL-3.0-or-later；官方内容、API 与依赖来源见 [致谢](docs/CREDITS.md)。

当前部署验证见 [VERIFICATION.md](docs/VERIFICATION.md)：默认APP扫码与11类本人接口已验证连通性；游戏官号/华为登录尚未接通。Bot个人文件采用内存上传，CLI不自动保存明文账户JSON/二维码。
