# 三国杀移动助手 · SGS-Mobile-Plugin

面向 [三国杀移动版](https://www.sanguosha.cn/) 的原创插件，聚合移动版官网资料与官方「[三国咸话](https://xh.sanguosha.cn/web/2)」社区。仅支持移动版，不使用 OL、十周年、欢乐三国杀等版本接口。

Bot 的帮助、公开资料及本人查询默认显示图片卡片：帮助分类、11 种道具独立图标、战绩胜率与胜负列表、近期对局和本人拥有分页。默认帮助直接读取预生成文件；标准动态卡片自带原生渲染，也可复用同级 AI-Plugin 的纯渲染服务，个人 SVG 和图片只在内存生成，账户继续加密保存。命令末尾加 `文字` 可看文字版；支持导出的本人查询加 `导出` 可发送已脱敏 JSON。渲染接入见 [渲染说明](docs/RENDERING.md)，素材证据见 [素材清单](docs/ASSETS.md)。

当前统一使用官方微信扫码 `pc-scan-v7`：本人资料、游戏资料、将力、能力、分模式战绩与胜率、近期对局、擅长武将、11类资产，以及本人拥有武将/皮肤分页均已接入当前官方接口并进行授权只读验证。本人拥有列表每页12项，武将支持势力筛选。旧 APP 扫码入口及旧版个人查询协议已移除，不混用凭据或回退旧接口。**官号、华为游戏独立登录仍未接通**；当前扫码是官方三国咸话社区授权。接口范围与证据见 [API 审计](docs/API-AUDIT.md)，早期验收作为历史记录保存在 [VERIFICATION.md](docs/VERIFICATION.md)。

## 安装与配置

需要 Node.js 22.15 或更高版本。

```sh
git clone https://github.com/719083594/SGS-Mobile-Plugin.git
cd SGS-Mobile-Plugin
npm install --ignore-scripts
node cli.mjs init
npm test
node cli.mjs diagnose
```

CLI 示例中的 `YOUR_QQ` 替换为本人 QQ 号；不要把真实身份或凭据写入公开脚本：

```sh
node cli.mjs command YOUR_QQ "#sgs帮助"
node cli.mjs command YOUR_QQ "#sgs资讯"
```

TRSS/云崽：将本目录安装到 Bot 的 `plugins/SGS-Mobile-Plugin`，在插件目录执行安装、初始化，将 `config/local.json` 的 `adapter` 改为 `"yunzai"`，重启 Bot，再发送 `#sgs帮助`。动态图使用本插件安装的 sharp 0.35.5，可独立转换；同级 `plugins/AI-Plugin` 包含 `src/rendering/index.mjs` 时优先复用其纯渲染服务，无需 AI 模型或密钥。`orangejuice.plugin.json` 提供橙汁中文配置入口。`adapter: "none"` 只启用 CLI/独立 API，不向云崽注册命令。

初始化自动生成实例加密密钥。需要扫码和本人查询时，确认实例 `personalDataEnabled: true`；设为 `false` 停止创建授权、查询扫码状态和读取本人数据，仍允许退出已有授权。完整参数表与上线检查见 [功能与配置清单](docs/FEATURES.md)。修改适配器、前缀、超时或缓存后重启，使已创建的客户端与命令规则使用新配置。

旧实例更名升级时，一并保留原 `config/local.json` 和 `data/`，只把实例的 `prefix` 改为 `"#sgs"`；不要重建或更换 `credentialsKey`。目录名和命令前缀不参与账户加密，历史加密命名空间保持兼容。旧协议授权需要使用当前微信流程重新登录；等待期间保留原本地记录，只有当前本人校验成功才替换并删除旧凭证。

武将名称可直接接在 `#sgs` 或 `#sgs武将` 后，支持省略名字中点，如 `势邓艾` 对应官网的 `势·邓艾`；势、界、神等前缀仍区分。直接输入名称须唯一精确匹配；部分名称检索请用 `#sgs武将 关键词`。同名多条时使用官网目录 ID，不自动选择。账户和授权命令仍按表中完整写法输入。

公开图鉴无需授权，可在群内查询。武将每页 24 项、皮肤每页 12 项，图片标明总数、当前页及下一页指令；末尾加 `文字` 可看文字列表。`全部武将` 指移动版官网已收录目录，皮肤图鉴指官网导航链接的「皮肤绘影堂」公开展示，均不宣称覆盖客户端全部内容，也不代表本人拥有。指定皮肤武将按官方字段精确匹配，神、界、势等前缀保持区分。皮肤原画缩略图预先保存在本插件 `resources/skin-gallery/`，按官方条目 ID 和原图 URL 精确匹配，不调用在线绘图服务；未收录图片会明确显示占位，不借用其他皮肤图。数据和素材范围见 [图鉴说明](docs/CATALOG.md)。

`#sgs我的武将 [势力] [页]`、`#sgs我的吴国武将 [页]`、`#sgs我的皮肤 [页]` 查询本人已授权拥有列表，仅私聊，每次读取官方的一页12项并返回一张原生图片。例如 `#sgs我的武将 吴 2`；势力支持魏、蜀、吴、群、神。图片和文字分别显示官方全部拥有总数、当前筛选匹配数、本页条数及下一页指令；翻页时保留势力。当前微信接口已经在内存中逐页核验武将和皮肤，ID 无重复、条目均为官方 `isHave:true`、计数稳定、末页和越界页符合分页规则。Bot 仍按需查询当前页，不一次下载或保存整份本人收藏。本人皮肤暂不支持按武将名搜索；`#sgs关羽皮肤` 是公开图鉴。`#sgs皮肤` 或 `#sgs皮肤 2` 等同对应页的 `#sgs我的皮肤`；`#sgs武将收藏` 是 `#sgs我的武将` 的兼容命令，查询官方拥有列表。旧社区“我的喜欢”查询已删除。

本人武将与皮肤视图优先使用本次响应 `url` 给出的官方图片，按固定域名与对应固定目录匿名读取，不发送账号凭据，拒绝重定向和查询参数，沿用图片大小、像素、并发与超时限制。图片和渲染结果只在内存，不保存本人收藏图库；武将图片不可用时可回退唯一精确名称匹配的本地头像，不按本人内部 ID 猜配图。资源缺失时显示占位，不借用其他版本武将或皮肤。

胜率和战绩模式可用 `全部/0`、`排位/1`、`身份/2`、`国战/3`、`斗地主/4`，如 `#sgs势周瑜胜率排位`。战绩图展示所选模式的官方正式统计，以及单独计算的本模式近期本批前10条样本胜率；近期图片最多展示本批前10条，不能代替完整历史。官方即使收到size=10也可能返回更多，本批完整安全结果可私聊导出。所选模式会映射为当前官方接口的模式参数，页面不混用其他模式的胜场或分母。

指定武将按所选模式读取官方擅长武将胜场/场次，不用其他模式或近期使用列表回填；默认查询全部模式。官方未证实完整武将生涯胜率端点，没有返回的武将不当作 0%。胜率命令末尾也可加 `导出`，仅在本人私聊导出已筛选的统计字段。

`#sgs官号登录` 明确返回官号游戏协议未接通状态与官方操作指引，不会启动社区扫码。查询已关联角色的本人资料，请另行使用 `#sgs登录`。`#sgs华为登录` 返回未接通状态和官方操作指引。游戏身份登记与社区授权独立，解绑身份不会删除社区会话，删除会话请发送 `#sgs退出授权`。

个人字段依据当前官方笔记战绩页面与社区前端绑定的标签制作中文摘要，未知字段保留在已脱敏 JSON 中，不猜成余额、排名或拥有列表。字段与标签证据、百分比口径见 [本人字段说明](docs/PERSONAL-FIELDS.md)。

## 本人扫码流程

1. 私聊 Bot 发送 `#sgs登录`，用微信「扫一扫」扫描收到的官方新版二维码，在官方网页完成登录确认。无需向 Bot 或聊天发送密码、Cookie、令牌。插件本地编码二维码，不使用第三方绘码服务；二维码不得转发。
2. 私聊发送 `#sgs扫码状态`。只有官方票据交换成功，并通过本人资料中的 `userId` 严格校验后，插件才保存会话。待扫码、过期或验证失败都不会显示授权成功。
3. `#sgs授权状态` 查看本人本地已保存的授权协议与待扫码状态，不输出凭据，也不等于实时验证令牌仍有效。
4. 如需取消这次扫码，发送 `#sgs取消扫码`，保留原本地授权记录。不再使用时发送 `#sgs退出授权`，清除本人全部本地授权和待扫码内容；即使远程注销失败，本地仍删除，不承诺注销官方其他客户端。

生成二维码时保留原本地授权记录。本人校验成功后，才以一次加密写入替换主会话并移除本 Bot 旧凭证、旧待扫码和新版待扫码内容。过期、失败或取消扫码保留原本地授权记录；停止支持的旧协议不会因此恢复查询。旧扫码入口已移除，`#sgs扫码状态` 只处理当前微信扫码请求；旧待扫码请求不能继续交换凭据。

当前本人查询统一使用微信社区会话和当前官方接口。本人拥有分页已在内存逐页核验拥有标志、计数与边界，Bot 每次仍只读取当前页；战绩与近期本批样本分别展示范围，不宣称覆盖全部 APP 信息或完整对局历史。二维码期限使用服务器 `expireIn`，会话有效期以官方实际响应为准。

CLI 输出文本和 JSON 到终端，不自动创建明文本人 JSON 文件或二维码图文件；授权状态仍由加密库管理。CLI 遇到二维码会提示去 Bot 私聊获取。Bot 在内存中生成二维码、通过 Buffer 发送个人 JSON 文件，不写插件明文临时文件；超过 8 MiB 的原始 JSON 在内存中 gzip，发送 `.json.gz`，压缩后仍超过内存上传上限则拒绝。协议端不支持好友文件发送时会明确提示。自行保存终端输出或收到的个人文件时，由本人管理访问权限。

## 数据与隐私

身份登记、社区会话和待扫码内容按 QQ 号隔离，整体使用 AES-256-GCM 加密保存到 `data/sessions.enc.json`。密钥保存在 `config/local.json`；这两者均被 Git 忽略，备份应存放在私有位置。直接修改密钥会使旧会话无法解密。旧版身份 JSON 仅在加密保存、读取回验一致、旧文件及路径确认未变化后删除；不一致、损坏或密钥错误时保留原文件。

插件不接收密码或验证码；本人结果递归过滤凭据、联系方式、实名及设备标识等字段。群内仅可展示发送者自己的胜率、战绩、近期战绩、将力、能力和擅长武将，结果再次按游戏统计字段白名单筛选；不能指定另一个 QQ 或角色的授权。其他个人资料、所有 JSON 导出、扫码和账户操作仍只允许私聊。API 返回官方来源，不将公开武将皮肤图当作本人拥有；社区喜欢接口已删除。当前微信扫码和已接入查询经过授权验证；未公开私人数量、凭据或原始响应。更广的 APP 覆盖和不同角色的数据一致性仍需逐项核对。每位新用户须使用自己的社区授权。

独立调用通过 `api.mjs` 导出的 `MobilePublicClient`、`CommunityAuthClient`、`SanguoshaMobile` 使用。公开数据模块无需登录；独立 API 使用者负责保存自己的会话，不能向其他用户公开授权对象。
