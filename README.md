# 三国杀移动助手 · SGS-Mobile-Plugin

面向 [三国杀移动版](https://www.sanguosha.cn/) 的原创插件，聚合移动版官网资料与官方「[三国咸话](https://xh.sanguosha.cn/web/2)」社区。仅支持移动版，不使用 OL、十周年、欢乐三国杀等版本接口。

Bot 的帮助、公开资料及本人查询默认显示图片卡片：帮助分类、11 种道具独立图标、战绩胜率与胜负列表、近期对局和收藏分页。默认帮助直接读取预生成文件；标准动态卡片使用同级 AI-Plugin 的共享原生渲染服务，个人 SVG 和图片只在内存生成，账户继续加密保存。命令末尾加 `文字` 可看文字版，加 `导出` 可发送已脱敏 JSON。渲染接入见 [渲染说明](docs/RENDERING.md)，素材证据见 [素材清单](docs/ASSETS.md)。

0.1.0 已完成真实用户三国咸话 APP 扫码，社区会话按本人隔离并用 AES 加密保存；线上 11 类本人接口均成功返回，官网资讯、刘备详情和 today 热榜也已成功查询。**接口字段的业务含义尚未与 APP 一一核对；官号游戏登录、华为渠道游戏登录仍未接通。** 社区授权、登记游戏 ID、取得某条本人数据分别记录，不会自动标成游戏渠道登录成功。脱敏验收结果见 [VERIFICATION.md](docs/VERIFICATION.md)。

## 安装与配置

需要 Node.js 22.15 或更高版本。

```sh
git clone https://github.com/719083594/SGS-Mobile-Plugin.git
cd SGS-Mobile-Plugin
npm install --ignore-scripts
node cli.mjs init
npm test
node cli.mjs diagnose
```

CLI 示例中的 `YOUR_QQ` 替换为本人 QQ 号；不要把真实身份或凭据写入公开脚本：

```sh
node cli.mjs command YOUR_QQ "#sgs帮助"
node cli.mjs command YOUR_QQ "#sgs资讯"
```

TRSS/云崽：将本目录安装到 Bot 的 `plugins/SGS-Mobile-Plugin`，在插件目录执行安装、初始化，将 `config/local.json` 的 `adapter` 改为 `"yunzai"`，重启 Bot，再发送 `#sgs帮助`。动态图另需同级 `plugins/AI-Plugin` 包含 `src/rendering/index.mjs`；复用本插件安装的 sharp 0.35.5，无需 AI 模型或密钥。`orangejuice.plugin.json` 提供橙汁中文配置入口。`adapter: "none"` 只启用 CLI/独立 API，不向云崽注册命令。

初始化自动生成实例加密密钥。需要扫码和本人查询时，确认实例 `personalDataEnabled: true`；设为 `false` 停止创建授权、查询扫码状态和读取本人数据，仍允许退出已有授权。完整参数表与上线检查见 [功能与配置清单](docs/FEATURES.md)。修改适配器、前缀、超时或缓存后重启，使已创建的客户端与命令规则使用新配置。

旧实例更名升级时，一并保留原 `config/local.json` 和 `data/`，只把实例的 `prefix` 改为 `"#sgs"`；不要重建或更换 `credentialsKey`。目录名和命令前缀不参与账户加密，历史加密命名空间保持兼容，已保存授权无需重新扫码。

武将名称可直接接在 `#sgs` 或 `#sgs武将` 后，支持省略名字中点，如 `势邓艾` 对应官网的 `势·邓艾`；势、界、神等前缀仍区分。直接输入名称须唯一精确匹配；部分名称检索请用 `#sgs武将 关键词`。同名多条时使用官网目录 ID，不自动选择。账户和授权命令仍按表中完整写法输入。

公开图鉴无需授权，可在群内查询。武将每页 24 项、皮肤每页 12 项，图片标明总数、当前页及下一页指令；末尾加 `文字` 可看文字列表。`全部武将` 指移动版官网已收录目录，皮肤图鉴指官网导航链接的「皮肤绘影堂」公开展示，均不宣称覆盖客户端全部内容，也不代表本人拥有。指定皮肤武将按官方字段精确匹配，神、界、势等前缀保持区分。皮肤原画缩略图预先保存在本插件 `resources/skin-gallery/`，按官方条目 ID 和原图 URL 精确匹配，不调用在线绘图服务；未收录图片会明确显示占位，不借用其他皮肤图。数据和素材范围见 [图鉴说明](docs/CATALOG.md)。

`#sgs皮肤`（别名 `#sgs我的皮肤`）仍是本人私聊的受保护接口；该接口返回部分官方预览，完整拥有列表尚未证实。`#sgs皮肤 关羽` 会查询公开皮肤图鉴。`#sgs武将收藏` 仍表示社区“我的喜欢”，不等同本人拥有武将。

胜率和战绩模式可用 `全部/0`、`排位/1`、`身份/2`、`国战/3`、`斗地主/4`，如 `#sgs势周瑜胜率排位`。战绩图展示所选模式的官方统计，以及单独计算的本模式近20场胜率。总览只解释已核实的总、排位、斗地主场次；身份或国战完整场次缺失时明确显示未返回。

指定武将按所选模式读取官方擅长武将胜场/场次；未指定模式时才可回退到近期使用武将统计，并明确标明周期和模式均未说明。官方未证实完整武将生涯胜率端点，没有返回的武将不当作 0%。胜率命令末尾也可加 `导出`，仅在本人私聊导出已筛选的统计字段。

`#sgs官号登录` 明确返回官号游戏协议未接通状态与官方操作指引，不会启动社区扫码。查询已关联角色的本人资料，请另行使用 `#sgs社区授权`。`#sgs华为登录` 返回未接通状态和官方操作指引。游戏身份登记与社区授权独立，解绑身份不会删除社区会话，删除会话请发送 `#sgs退出授权`。

默认 APP 协议的个人资料、将力接口资料、战绩、近期战绩、资产和游戏资料会按官方前端已证实的字段显示中文摘要；未知字段保留在完整已脱敏 JSON 中，不猜成余额、排名或拥有列表。字段与标签的官方证据、百分比口径见 [本人字段说明](docs/PERSONAL-FIELDS.md)。

## 本人扫码流程

1. 在官方三国咸话 APP 登录，并在 APP 内关联需要查询的三国杀移动版角色。
2. 私聊 Bot 发送 `#sgs社区授权`，使用三国咸话 APP 的「扫一扫」扫描收到的二维码，在官方界面确认。插件本地生成 PNG，二维码内容不会交给第三方绘码服务；二维码不得转发。
3. 私聊发送 `#sgs扫码状态`。只有官方返回凭证并通过本人社区资料接口验证后，插件才保存会话。待扫码、过期或验证失败都不会显示授权成功。
4. 逐项查询本人资料并与 APP 核对。胜率、战绩、将力、能力与擅长武将可在群里展示自己的结果；资产等敏感资料和所有完整导出仍请私聊。战绩模式：`0` 全部、`1` 排位、`2` 身份、`3` 国战、`4` 斗地主，也可直接填模式名称。官方返回未关联角色时，在官方 APP 处理，再重试。
5. 不再使用时发送 `#sgs退出授权`。即使远程接口异常，插件也删除本人本地会话。APP 扫码协议尚无已核实的远程撤销接口；其他客户端会话应在官方 APP 管理。

可选 `#sgs社区授权 微信` 使用新版社区微信扫码协议。此协议只接入已核实的社区资料、游戏概览、角色映射接口；当前 Bot 命令中仅 `#sgs个人资料` 对应其游戏概览，其他丰富资料请优先使用默认 APP 扫码协议。两套协议不混用凭证。APP 二维码的 120 秒是官方前端轮询窗口；会话有效期以官方实际响应为准。

CLI 输出文本和 JSON 到终端，不自动创建明文本人 JSON 文件或二维码图文件；授权状态仍由加密库管理。CLI 遇到二维码会提示去 Bot 私聊获取。Bot 在内存中生成二维码、通过 Buffer 发送个人 JSON 文件，不写插件明文临时文件；超过 8 MiB 的原始 JSON 在内存中 gzip，发送 `.json.gz`，压缩后仍超过内存上传上限则拒绝。协议端不支持好友文件发送时会明确提示。自行保存终端输出或收到的个人文件时，由本人管理访问权限。

## 数据与隐私

身份登记、社区会话和待扫码内容按 QQ 号隔离，整体使用 AES-256-GCM 加密保存到 `data/sessions.enc.json`。密钥保存在 `config/local.json`；这两者均被 Git 忽略，备份应存放在私有位置。直接修改密钥会使旧会话无法解密。旧版身份 JSON 仅在加密保存、读取回验一致、旧文件及路径确认未变化后删除；不一致、损坏或密钥错误时保留原文件。

插件不接收密码或验证码；本人结果递归过滤凭据、联系方式、实名及设备标识等字段。群内仅可展示发送者自己的胜率、战绩、近期战绩、将力、能力和擅长武将，结果再次按游戏统计字段白名单筛选；不能指定另一个 QQ 或角色的授权。其他个人资料、所有 JSON 导出、扫码和账户操作仍只允许私聊。API 返回官方来源，不将公开武将皮肤图当作本人拥有皮肤，也不将社区武将收藏当作拥有武将。APP 实扫及 11 类接口连通性已验证；字段业务含义、完整覆盖范围和不同角色的数据一致性仍需与官方 APP 逐项核对。每位新用户须使用自己的社区授权。

独立调用通过 `api.mjs` 导出的 `MobilePublicClient`、`CommunityAuthClient`、`SanguoshaMobile` 使用。公开数据模块无需登录；独立 API 使用者负责保存自己的会话，不能向其他用户公开授权对象。
