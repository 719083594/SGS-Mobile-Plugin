# 部署验收与剩余范围

记录日期：2026-10-07（Asia/Shanghai），版本 0.1.0。仅记录脱敏状态、接口类型与结构计数，不包含真实 QQ、游戏 UID、主机地址、Key、Token、Cookie、二维码内容或原始个人响应。

## 已完成的真实授权与线上请求

真实用户已使用官方三国咸话 APP 完成默认 `app-qr-v1` 扫码，官方本人社区资料验证成功，session 已按本人隔离、使用 AES-256-GCM 保存。以下 11 类本人接口在部署服务器均成功返回。

计数是现场响应检查的结构计数（对象字段或数组条目），**不等于游戏资产金额、本人拥有皮肤/武将数量或历史对局总数**。没有在此公开字段值，也没有完成与 APP 的逐字段业务核对。

| 查询 kind | 官方端点 | 检查计数 | 成功状态与解释边界 |
| --- | --- | --- | --- |
| `profile` | wxforum `/api/profile` | 30 | 社区本人资料成功；与游戏概览分别处理 |
| `summary` | wxforum `/api/user/getGameSummary` | 15 | 游戏概览成功；字段业务含义待逐项核对 |
| `force` | wxforum `/api/user/getGameForce` | 16 | 将力接口成功；数值口径、排名及更新时点待核对 |
| `records` | wxforum `/api/user/getGameRecord` | 2 | 战绩统计成功；不同模式、胜率口径待核对 |
| `recent` | wxforum `/api/user/getGameRecordList` | 20 | 近期对局成功；一页响应不代表完整历史 |
| `gameInfo` | hi-gateway `/api/game/v2/general/gameInfo` | 28 | 本人游戏资料成功；字段映射待核对 |
| `assets` | hi-gateway `/api/game/v2/general/property` | 12 | 本人资产接口成功；不从计数推断余额或资产数量 |
| `skins` | hi-gateway `/api/game/v2/general/generalSkins` | 3 | 本人皮肤接口成功；拥有状态、分组及完整列表待核对 |
| `abilities` | hi-gateway `/api/game/v2/general/abilities` | 9 | 本人能力接口成功；评分/指标口径待核对 |

以上是一个本人授权会话的实测，不将其会话开放给其他用户。新用户仍需自己的官方授权，接口是否返回其角色资料由官方实际响应决定。

公开查询在部署服务器成功：移动版官网资讯、刘备详情、`today` 今日热榜。早期匿名审计还验证过其他分类、攻略、模式及另外三种热榜；本条上线记录不把所有公开命令和所有 QQ 客户端投递自动视为已实测。

## 已核查的隔离、加密与输出行为

| 项目 | 当前实现/验证范围 |
| --- | --- |
| 本人/群聊隔离 | 授权、扫码状态、本人资料、身份绑定/列表/解绑只允许私聊；事件带 `group_id` 时优先拒绝个人操作。回归测试覆盖混合私聊标志及其他 QQ 无会话的情况 |
| 凭据与身份存储 | 整个 owner 数据映射包含登记身份、session 和待扫码内容，AES-256-GCM 加密；密钥在实例私有配置，源码与 GitHub 不包含实例文件 |
| 存储安全 | 拒绝符号链接/目录 junction，限制文件与明文大小，同步跨进程写锁及原子 `update()`；错误密钥、损坏密文不覆盖原文件，已有锁不擅自删除 |
| 回归证据 | 多个独立进程对同一 owner 的加密更新无丢失，大小/完整性/锁/目录链接边界通过；Windows 普通文件 symlink 测试曾因环境权限跳过，不将跳过项算通过 |
| 旧身份迁移 | 仅处理合法本人身份文件；检查目录与普通文件、大小上限，先加密保存并回读一致，再复查设备/文件身份/大小/内容及路径，最后仅删除该旧文件；冲突或错误保留原文件 |
| 退出与解绑 | 退出删除本人社区会话和待扫码内容，保留登记身份；即使上游退出失败仍清理本地授权。解绑仅删登记身份，不能当作退出社区会话。APP 协议远程撤销未核实 |
| Bot 二维码/文件 | 二维码在内存编码；个人 JSON 用 Buffer 上传，不在插件目录写明文临时文件。原始 JSON 大于 8 MiB 时在内存 gzip，发送 `.json.gz`；压缩后仍超上限则拒绝，协议端不支持文件时明确提示 |
| CLI | 只输出文本/JSON，遇到二维码提示去 Bot 私聊获取；不自动创建明文 JSON 文件或二维码图文件，授权状态仍由加密库管理。终端输出仍是本人资料，用户自行保存副本需自行管理访问权限 |

隔离与存储测试是代码/接口回归证据，不能替代全部真实 QQ 客户端的图片、文件及 gzip 解压验收。Bot 适配器采用内存传输，不在本记录中承诺外部消息平台或客户端不保存用户收到的文件。

## 配置的有效项与保留项

完整默认值、允许范围与重启要求见 [FEATURES.md](FEATURES.md)。不公开本次实例密钥或用户专属配置。

| 配置项 | 实际用途 |
| --- | --- |
| `enabled` | 命令处理开关 |
| `adapter` | `none` 为 CLI/API；`yunzai` 注册 Bot 命令，修改需重启 |
| `prefix` | 命令前缀，修改后重启更新已注册规则 |
| `timeoutMs`、`cacheSeconds` | 官方请求超时、公开资料缓存；本人响应不走公共缓存 |
| `maxReplyChars`、`maxItems` | 回复/转文件阈值及部分公开列表数量；格式器/方法还可能有自己的上限 |
| `credentialsKey` | 真正用于 AES 的实例密钥；初始化随机生成，不随意更换，不公开 |
| `personalDataEnabled` | 真正控制创建社区授权、扫码状态及本人查询；关闭仍允许退出已有授权 |
| `channels.official`、`channels.huawei` | 允许对应渠道的身份登记，不是游戏登录开关 |
| `masters` | 当前核心保留字段，未用来决定个人查询权限；橙汁配置声明另设 `ownerOnly` |
| `officialSite`、`communitySite` | 保留的来源展示字段；请求使用代码内固定官方端点，不用这两个字段改写请求地址 |

## 仍不能宣称完成的项目

- 官号游戏登录和华为渠道游戏登录仍未接通。`#三国官号登录` 只是社区 APP 扫码兼容入口，`#三国华为登录` 返回真实未接通状态；社区会话保留 `gameAuthenticated:false`、`channelVerified:false`。
- 默认 APP 授权成功不等于新版 `pc-scan-v7` 微信方式完成本人验收；微信方式的票据交换、本人资料与角色映射仍需单独验证。
- 字段的业务意义、游戏角色一致性、模式/分页统计口径、拥有状态和完整覆盖范围尚未与 APP 一一核对。11 个接口成功不等于“绝大多数信息已全部正确展示”或“比 APP 更丰富”。
- 社区收藏不是拥有武将列表，公开皮肤图也不是本人拥有皮肤。本次空收藏仅代表该接口返回为空。
- 完整拥有武将列表、完整游戏排行榜和完整历史对局覆盖仍未证实；真实 QQ 客户端的所有图片/文件投递需要按目标协议端验收。

协议与早期匿名结果见 [API-AUDIT.md](API-AUDIT.md)，官方/API/软件来源见 [CREDITS.md](CREDITS.md)。
