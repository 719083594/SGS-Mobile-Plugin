# 武将与皮肤图鉴

本功能仅查询三国杀移动版官方公开资料，不需要社区授权；可在群里使用。公开图鉴与本人拥有列表具有独立的数据来源和范围。

| 查询 | 命令 |
| --- | --- |
| 官网已收录的全部武将 | `#sgs全部武将`、`#sgs全部武将 2` |
| 吴国武将 | `#sgs吴国武将`、`#sgs吴国武将 2` |
| 其他势力 | `#sgs魏国武将`、`#sgs蜀国武将`、`#sgs群雄武将`、`#sgs神武将` |
| 通用势力分页 | `#sgs武将列表 吴 2`，势力可用全部、魏、蜀、吴、群、神 |
| 官方公开皮肤展示 | `#sgs皮肤图鉴`、`#sgs全部皮肤 2` |
| 指定武将的公开皮肤 | `#sgs关羽皮肤`、`#sgs皮肤图鉴 关羽` |
| 官网皮肤分类 | `#sgs皮肤图鉴 至尊 2`、`#sgs皮肤图鉴 关羽 传说` |

武将每页 24 项，皮肤每页 12 项。页码超出范围时直接提示有效页数，不跳到其他页面。图片显示本页数据、筛选条件、总数、页数和可直接复制的下一页命令。查询末尾加 `文字` 可取得同一页的文字版。皮肤按官方武将字段精确匹配，保留神、界、势等前缀，不自动合并不同版本。

## 官方数据范围

武将来源为 [移动版官网武将目录](https://www.sanguosha.cn/pc/hero-list.html)。页面自身包含完整官网目录及全、魏、蜀、吴、群、神分组，插件只解析正式目录，排除顶部热门推荐。按官网分组关联势力，不按人物历史或名字推测势力；官网结构缺失、分组冲突或分页不一致时明确失败。官网“全部”表示官网已收录条目，不代表客户端一定全部收录，也不代表本人拥有。

皮肤来源为移动版官网导航的 [皮肤绘影堂](https://share.sanguosha.cn/skins/)，使用公开只读 `GET https://share.sanguosha.cn/api/skins/list?type=1&page=1&limit=100`，三种官方分类分别为 `1` 至尊、`2` 传说、`3` 原画。分页信息来自 `data.lists` 的 `total/current_page/per_page/last_page/data`。插件按有界分页取得所选分类，核对页号、总数、条目唯一性后筛选，并在 Bot 中再次按每页 12 条分页。这个展示站并非客户端全皮肤数据库；同名不同状态按官方 ID 保留，不以名字去重。

## 图片与维护

武将头像沿用 `resources/ui/assets/` 的官方素材和哈希清单。公开皮肤缩略图来自皮肤绘影堂 API 声明的 `sjwx-oss.sanguosha.cn/skins/image/` 原图，构建脚本匿名读取、校验栅格格式与尺寸后缩为本地 JPEG，来源和缩略图哈希记入 `resources/skin-gallery/manifest.json`。素材权利归游戏及各原作者。

线上查询不会下载皮肤原图。只有官方条目 ID 与原图 URL 都匹配清单，才显示已验证本地图；新条目或图源变化显示明确占位，维护者可显式运行 `node scripts/build-skin-assets.mjs` 更新公开素材。构建器和线上读取器不读取账号、Cookie 或私有配置。动态目录图片通过同级 AI-Plugin 的共享原生渲染器在内存生成。

本人私聊的 `#sgs我的武将 [页]`、`#sgs我的皮肤 [页]` 使用独立的 `generalSkins` 受保护接口，并从 `gameInfo.generalNum/skinNum` 读取官方拥有总数。每页24项仅对本次已返回的 `generalList/skinList` 分页，不能用本地翻页获得接口未返回的条目。结果明确区分拥有总数与本次返回数量；缺少已核实的全量分页和势力字段，不能宣称全部拥有或完整本人吴国列表。`#sgs皮肤` 保留原始摘要与导出。社区 `general/getMyLike` 是“我的喜欢”，不是拥有武将；不将其与公开图鉴的 ID 擅自关联。个人条目、私密响应和渲染图只在内存处理，不打包到仓库。

公开图鉴的588张武将头像与141张绘影堂皮肤缩略图均随插件保存在 `resources/ui/assets/` 和 `resources/skin-gallery/`，包含在 Git 克隆及归档中；响应期间通过本地清单校验，不临时下载原图。原创道具 SVG 使用固定 LF 换行，确保 Windows 和 Linux 的字节校验一致。
