# 图片界面

TRSS/云崽适配器默认把 `#三国帮助`、资讯/公告/活动、武将、攻略、模式、社区与热榜查询转为深蓝金色资料卡。本人资料、资产、战绩、近期战绩、将力、游戏资料、皮肤、武将收藏、能力和擅长武将各有对应标题与布局。字段依据官方前端已核实的协议；未证实的结构用条目卡展示官方字段，不把未知数量猜成余额或拥有列表。

资产显示 11 种独立道具图。六种图来自官方公开素材，五种使用原创矢量图；图像与字段证据的差异逐项记录在 [ASSETS.md](ASSETS.md)。缺少字段时不编造零余额。战绩显示模式胜率、段位、近期胜负与常用武将；近期战绩仅显示已返回的时间、模式、胜负与官方武将头像，不猜缺失武将名、单场 MVP 或排名。

公开武将图和道具图附带来源、SHA-256 与大小清单，读取时核验。近期战绩头像来自官方静态 `sjpubicres.sanguosha.cn/release/character_heads/`，仅固定 HTTPS 域名和路径的匿名 GET，不带社区授权、Cookie 或其他凭据，不跟随重定向；只在本次请求内保留，大小、张数、总量与时间有界。任意用户头像、签名链接与外部 URL 不加载。

每张图 1080 像素宽，长列表按图分页并限制最多八张；达到上限时注明节选，可用完整导出获取其余字段。缺数据、缺图和未知结果均明确显示。`#三国帮助 文字`、`#三国资产 文字` 等返回文字；`#三国资产 导出` 等继续走本人文件导出，避免图片代替完整数据。

本人图只允许私聊，在授权校验和本人接口查询成功后构建。适配器和发送层同时拒绝群上下文。APP 协议战绩采用下述原生内存绘图；其他动态卡共用宿主 Browser、新建临时 BrowserContext，页面禁用脚本、外部网络、缓存，资源仅限已核验本地文件与受控内存 PNG/JPEG。图片以 JPEG Buffer 发送，所有 SVG、HTML、头像与本人图都不落明文临时文件；账号和会话仍由原 AES-256-GCM 库管理。图片故障回退原文字/内存文件结果。

独立 API 与 CLI 默认继续返回文字/JSON，不启动图片渲染。公开文档截图中的数字、昵称与战绩全部为合成排版示例；真实本人资料不提交 GitHub。

TRSS 适配器明确选择 `loader.getRenderer('puppeteer')` 并核对实例接口，避免默认入口返回分发器而没有 `browserInit`。失败日志仅保存固定错误代码，不记录个人 HTML、原始异常正文或授权信息。

独立渲染 API 默认等待关闭确认。bot 适配器把有效图片交付与清理分开：完整校验图片并实际启动上下文关闭后即可发送，共享队列继续等待 `drain()` 真实确认关闭后才准许下一张图建立页面。关闭迟到不再丢弃有效图片，拒绝或永久挂起仍阻止新页面；等待任务至多四个、最长三十秒。本人资料、资产、战绩及其 HTML 均不缓存。

默认前缀公开帮助直接发送随包发布的 `resources/ui/help.jpg`，核验源码版本和图片 SHA-256，无需浏览器或渲染队列。自定义前缀才动态构建并缓存公开帮助十分钟。战绩前 24 个近期武将与统计、胜负合为一张图，更多才续页。截图直接裁剪已校验容器，避免额外观察器、滚动与测量；只记录固定阶段的耗时。后页失败时提示已发送页数，不再误报整份图片未生成或重复完整文字。

`app-qr-v1` 的 `#三国战绩` 直接生成受限 SVG，用锁定版本 `sharp` 在本机内存转换 JPEG，不启动浏览器、不等待其他页面关闭，也不在失败后再尝试浏览器。它使用独立的单并发队列，最多四个等待任务、最长三十秒；渲染库限制处理时间、输入/输出尺寸与字节，并关闭 libvips 操作缓存。`sharp` 的缓存和线程设置属于进程内该库的全局设置。

原生战绩只嵌入已核验的公开武将 PNG/JPEG：精确名称优先，无精确项时仅忽略官网名称中的中点 `·`（例如 `势邓艾` 对应 `势·邓艾`），完整保留界、势、神等版本前缀，并要求文件、哈希和大小唯一。固定素材目录、普通文件、清单哈希、读取前后身份检查均通过才可用，未知或歧义名称显示占位。SVG 文本转义并逐标签/属性检查，拒绝外部地址、脚本、DTD 和自定义实体，内嵌图的压缩字节与解码像素也有总量限制。指标只记录固定后端名、耗时与错误代码。其他协议或卡片继续使用相应原有布局，不把原生战绩验收扩大为所有个人图片已验收。

固定帮助图生成时显式传入公共素材读取器，顶部刘备、关羽、诸葛亮、赵云使用各自公开头像；发布前检查四图加载完成、无占位，并随图片更新校验清单。日常命令仍只读取已生成的帮助文件。
