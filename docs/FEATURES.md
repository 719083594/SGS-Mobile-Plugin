# 功能与配置

当前版本：0.1.0，核验日期：2026-10-07。只支持三国杀移动版；官方三国咸话微信扫码是当前实际登录方式，官号与华为游戏独立登录未接通。本人查询统一 `pc-scan-v7`，旧 APP 扫码和旧个人查询协议已删除，无旧授权回退。公开来源与当前授权接口见 [API-AUDIT.md](API-AUDIT.md)。

帮助与固定说明直接读取预生成图片；动态卡使用同级 AI-Plugin 共享原生渲染，个人图片只在内存生成。安装依赖见 [RENDERING.md](RENDERING.md)。命令末尾加 `文字` 查看文字版；支持导出的统计命令末尾加 `导出`，文件仅发本人私聊。

## 公开命令

以下采用默认前缀 `#sgs`，公开命令可在群聊使用且无需登录。

| 命令 | 范围 |
| --- | --- |
| `#sgs帮助`、`#sgs功能`、`#sgs状态` | 帮助、能力与运行状态 |
| `#sgs资讯`、`#sgs活动`、`#sgs公告`、`#sgs详情 公告ID` | 移动版官网列表与原文；图片内的将池/概率不伪造 OCR 名单 |
| `#sgs武将 刘备`、`#sgs武将势邓艾`、`#sgs势邓艾` | 武将详情、技能和模式资料；直接名称需唯一精确匹配，模糊检索使用“武将 关键词” |
| `#sgs全部武将 [页]`、`#sgs吴国武将 [页]`、`#sgs武将列表 蜀 2` | 官网已收录武将，每页24项，支持魏/蜀/吴/群/神 |
| `#sgs皮肤图鉴 [武将] [分类] [页]`、`#sgs关羽皮肤` | 官方绘影堂公开展示，每页12项，分类至尊/传说/原画 |
| `#sgs攻略 [关键词]`、`#sgs模式 身份场` | 官网攻略/模式；带关键词的攻略搜索为社区投稿 |
| `#sgs社区 [关键词]`、`#sgs热榜 today/week/all/theme` | 公开帖子、搜索、热榜；week/all是社区人气榜，不是游戏战力榜 |

官网图鉴和绘影堂不等同客户端全集，更不代表本人拥有；目录和素材范围见 [CATALOG.md](CATALOG.md)。公开 ID、本人内部 ID 和绘影堂 ID 不猜测互相转换。

## 微信登录与本地账户

扫码与本人查询需要 `personalDataEnabled: true`，以下账户操作仅本人私聊。

| 命令 | 行为 |
| --- | --- |
| `#sgs登录` | 发送本地编码的官方微信二维码；用微信扫一扫，在官方网页确认，不向 Bot 发送密码或登录凭据 |
| `#sgs扫码状态` | 查询进度；票据交换与官方本人 `userId` 校验都成功，才加密保存当前会话 |
| `#sgs授权状态` | 查看本地授权/待扫码状态，不输出凭据，不等于实时验证令牌仍有效 |
| `#sgs取消扫码` | 清除本次待扫码，保留原本地授权记录 |
| `#sgs退出授权` | 清除本人全部本地会话和待扫码；远程注销失败也清理本地，不承诺注销官方其他客户端 |
| `#sgs绑定 官号或华为 游戏ID [区服]`、`#sgs账户`、`#sgs解绑 [渠道]` | 加密登记、查看或删除本人身份；未验证游戏角色归属，不代表渠道登录成功 |
| `#sgs官号登录`、`#sgs华为登录` | 仅说明游戏登录未接通状态及官方指引，不创建相应游戏会话 |

生成新二维码时不删除原本地授权记录；失败、过期或取消均保留。只有当前票据及本人身份严格验证成功，才原子替换主会话并移除本 Bot 旧凭证和全部待扫码内容。旧记录仅用于安全清理，旧协议查询不可用。成功建立的是 `sanguosha-community`，仍为 `gameAuthenticated:false`、`channelVerified:false`，不宣称官号/华为游戏渠道认证。

## 本人查询

所有下列查询已接入当前官方接口并做授权只读验证。群统计只使用发送者自己的会话，再按游戏统计白名单投影；不能指定他人的 QQ、角色或授权。敏感资料、拥有列表和全部 JSON 导出仅本人私聊。

| 命令 | 当前官方接口/显示 | 群内展示 |
| --- | --- | --- |
| `#sgs个人资料` | `gameSummary`：概览、拥有数量与官方总数分别显示 | 否 |
| `#sgs游戏资料` | `generalGameInfo`：官方资料、段位和有效场次计算的胜率 | 否 |
| `#sgs资产` | `gameProperty`：11类道具独立图标；缺失不填0 | 否 |
| `#sgs将力 [模式]` | `gameForce`：综合/斗地主/排位/国战/身份五项战力；未解释字段保留原名 | 是，本人 |
| `#sgs能力` | `gameGeneralAbilities`：官方能力返回值，不猜字段含义 | 是，本人 |
| `#sgs战绩 [模式]` | `gameCareerUserInfo` 正式统计，另展示本模式近期本批前10条样本 | 是，本人 |
| `#sgs近期战绩 [模式] [页]` | `gameRecordList/total`：图片最多展示本批前10场，只显示本人明确武将及本人结果 | 是，本人 |
| `#sgs擅长武将 [模式]` | `gameBestGeneralNew`：所选模式的官方擅长武将子集，不能当作拥有目录 | 是，本人 |
| `#sgs胜率 [模式]`、`#sgs势周瑜胜率排位`、`#sgs胜率 势周瑜 身份` | 总览/指定武将的当前模式胜场与场次；缺失不当作0%，不跨模式回填 | 是，本人 |
| `#sgs我的武将 [势力] [页]`、`#sgs我的吴国武将 [页]` | `gameGeneral/total`：官方拥有武将，每页12项；势力魏/蜀/吴/群/神 | 否 |
| `#sgs我的皮肤 [页]` | 同端点官方拥有皮肤，每页12项，不支持按武将搜索 | 否 |

`#sgs皮肤 [数字页码]` 等同对应页的 `#sgs我的皮肤`；`#sgs武将收藏` 是 `#sgs我的武将` 的兼容命令，已删除旧社区“我的喜欢”接口，不再表示社区点赞收藏。公开 `#sgs关羽皮肤` 与本人拥有列表是不同来源。

模式支持 `全部/0`、`排位/排位赛/1`、`身份/身份场/2`、`国战/3`、`斗地主/欢乐斗地主/4`。Bot编号映射为当前官方 `mode` 的 `0/4/1/2/3`；传输参数不会直接套旧模式编号。近期图片/样本只取本批前10条，未知结果排除，不能代表完整战绩胜率。请求size=10不保证官方只返回10条；插件有界接受最多100条安全结果，私聊JSON导出保留完整本批。指定武将只在所选模式的擅长武将子集中精确匹配；神、界、势保持区分。总览、分项比例和近期样本分别标明范围。

拥有页分别显示 `have` 全部拥有、`searchNum` 当前筛选匹配、原 `total` 游戏总数及本页条数；下一页保留武将势力。全页 RAM 核验确认拥有标志严格true、计数稳定、ID无重复及首末页/越界边界；Bot实际每条命令只取当前12项。无效条目或计数不一致整页拒绝，不静默过滤后称完整。内部 `id/generalId` 不猜配公开图鉴。皮肤原画匿名读取固定官方资源目录，仅留本次内存；品质小标不冒充皮肤原画。

如 `#sgs资产 导出`、`#sgs战绩 2 导出`、`#sgs近期战绩 0 1 导出` 发送该次查询的已脱敏 JSON，仅本人私聊。拥有投影命令不提供全量导出。群结果及其文字回退不会自动附原始 JSON 或文件。Bot采用内存Buffer上传，大 JSON 在内存gzip；CLI只输出终端文本/JSON，不自动保存本人数据或二维码。官方未关联角色时提示先在官方页面关联；会话失效时要求重新微信扫码，不虚构有效期或刷新能力。字段证据见 [PERSONAL-FIELDS.md](PERSONAL-FIELDS.md)。

## 尚未支持

官号、华为游戏独立授权与渠道角色认证、完整游戏排行榜、完整对局历史和与官方APP逐功能全面对照尚未完成。不提供签到、点赞、分享、兑换、充值/交易或代操作。现有社区访问不证明游戏渠道登录，公开目录也不证明客户端全集。

## 配置参数

配置示例为 `config/example.json`；初始化产生 `config/local.json`。实例文件、加密会话与身份登记不提交 GitHub。个人 JSON/二维码不由 CLI 自动落盘，Bot 内存上传也不写插件明文临时文件。数值需在下列范围内，修改后重启 Bot。

| 字段 | 默认值 | 实际作用 |
| --- | --- | --- |
| `enabled` | `true` | 启用命令处理；`false` 时不处理插件命令 |
| `adapter` | `"none"` | `none` 为 CLI/API；`yunzai` 注册 TRSS/云崽命令，修改需重启 |
| `prefix` | `"#sgs"` | 命令前缀，长度 1–20 |
| `timeoutMs` | `12000` | 官方请求超时毫秒，1000–60000 |
| `cacheSeconds` | `300` | 公开资料缓存秒数，60–3600；本人资料不使用此缓存 |
| `maxReplyChars` | `3500` | 回复截断/本人摘要或原字段 JSON 转文件阈值，500–8000；公共格式器另有内部长度上限 |
| `maxItems` | `8` | 部分公开列表与本人数组摘要的条目上限，1–20；完整 JSON 导出保留接口层已读取的条目，武将/无关键词攻略还有各自默认上限 |
| `credentialsKey` | 初始化随机生成 | 64 位十六进制 AES-256-GCM 密钥；保留在实例中，不公开、不随意更换 |
| `channels.official` | `true` | 允许登记官号游戏身份，不是官号登录开关 |
| `channels.huawei` | `true` | 允许登记华为游戏身份，不是华为登录开关 |
| `masters` | `[]` | 保留字段；当前核心未用作授权控制。橙汁实例配置入口由其 `ownerOnly` 管理 |
| `officialSite` | `https://www.sanguosha.cn/` | 来源展示字段；请求使用代码内核验过的固定官方端点，不用此字段改写请求地址 |
| `communitySite` | `https://xh.sanguosha.cn/web/2` | 来源展示字段；同上 |
| `personalDataEnabled` | `true` | 社区授权与本人查询开关；`false` 停止开始授权、查询扫码状态和本人数据，仍允许退出已有授权；启用后仍需有效本人会话及协议支持，群内只允许上述统计项目 |

`credentialsKey` 与 `data/sessions.enc.json` 一起备份在私有位置。源码同步前检查 `.gitignore`；不要上传整个实例目录、导出 JSON、二维码或原始研究 HTML/JS。Linux 私密文件使用 0600 权限，Windows 仍需依靠所在目录的实际访问权限。

## 实例验证

自动化测试验证固定端点、字段合同、隐私隔离、加密完整性和图片解码；真实接口验证与 QQ 投递分别确认。上线时保留原密钥与加密数据，检查 `#sgs帮助`、公开资料、本人微信登录、资产、分模式战绩/胜率和拥有分页；使用第二个QQ确认不能读取他人会话。群内只能分享自己的统计，扫码、资产、拥有列表与全部导出只在本人私聊。源码同步前扫描跟踪文件，不上传私密配置、数据、二维码、账号响应或研究二进制。

官方来源和协议见 [API-AUDIT.md](API-AUDIT.md) 与 [CREDITS.md](CREDITS.md)；早期结果只作为 [历史验收记录](VERIFICATION.md)。
