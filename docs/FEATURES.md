# 功能、配置与上线检查

当前版本：0.1.0。仅支持三国杀移动版。下表中的“接口已接入”指原创客户端已实现并通过协议/模拟响应测试，**不代表已经有人完成扫码、取得本人资料或验证完整字段**。个人信息仍需本人在官方界面授权后现场验收。

## 命令清单

以下使用默认前缀 `#三国`；修改前缀后按实例配置使用。扫码授权、扫码状态和本人查询要求实例 `personalDataEnabled: true`；关闭此开关仍可退出已有授权。

| 命令 | 当前行为 | 登录要求/限制 |
| --- | --- | --- |
| `#三国帮助`、`#三国功能`、`#三国状态` | 查看用法与真实能力状态 | 无 |
| `#三国资讯` | 移动版官网资讯分类 | 公开资料 |
| `#三国公告` | 移动版官网最新分类 | 公开资料，不保证每项都是运营公告 |
| `#三国活动` | 官网活动公告分类 | 公开资料 |
| `#三国详情 公告ID` | 公告标题、正文和来源 | 公告 ID 从列表取得；图片内容需查看原文 |
| `#三国武将 [名称或ID]` | 名称检索武将及变体；数字 ID 返回详细资料/分模式技能 | 公开资料；先搜名称，再按 ID 查详情 |
| `#三国攻略` | 官网新手攻略列表 | 公开资料 |
| `#三国攻略 关键词` | 三国咸话攻略分类搜索 | 社区投稿，不保证官方攻略性质 |
| `#三国模式 名称或ID` | 官网人数、时长、玩法等介绍 | 身份场、排位赛、团战3V3、国战、欢乐斗地主、幻化之战、太虚幻境；对应 ID 1、2、3、4、5、7、8 |
| `#三国社区 [关键词]` | 最新公开帖子或关键词搜索 | 社区公开资料 |
| `#三国热榜 [today或theme或week或all]` | 今日帖子、热门话题、一周红人、著名大佬 | 默认 today；后两项是社区人气排行，不是游戏战力/排位榜 |
| `#三国社区授权` | 创建真实三国咸话 APP 扫码请求并发送本地二维码 | 仅本人私聊；不是游戏渠道登录 |
| `#三国社区授权 微信` | 创建新版社区微信扫码请求 | 仅本人私聊；支持的查询范围小于 APP 协议 |
| `#三国官号登录` | 兼容进入 APP 社区扫码流程 | 仅本人私聊；官号游戏登录未验证 |
| `#三国华为登录` | 返回华为游戏登录未接通状态与官方步骤 | 不创建华为会话 |
| `#三国扫码状态` | 查询当前本人二维码；验证本人社区资料后加密保存凭证 | 仅本人私聊；必须已创建扫码请求 |
| `#三国退出授权` | 删除本人本地加密社区会话/待扫码请求 | 仅本人私聊；新版尝试远程注销，旧版远程撤销未核实；远程失败不阻止本地删除 |
| `#三国绑定 官号或华为 游戏ID [区服]` | 按渠道分开登记本人游戏身份 | 仅本人私聊；未验证角色归属，不代表已登录或已关联社区角色 |
| `#三国账户` | 查看本人登记的游戏身份 | 仅本人私聊；展示未认证状态 |
| `#三国解绑 [官号或华为]` | 删除本人指定渠道身份；不带参数删除全部登记身份 | 仅本人私聊；社区会话独立，需另行退出授权 |

消息通常只显示摘要与原文链接。官网将池、概率、皮肤等图片可由独立 API 返回来源；当前 Bot 公开命令不自动 OCR，也不保证发送全部原图。分页、攻略详情等完整调用能力通过 `MobilePublicClient` 提供，当前命令表不含定时推送、签到或自动游戏操作。

## 本人查询命令与协议

默认 `app-qr-v1` 为 APP 扫码；`pc-scan-v7` 为可选微信扫码。成功建立的是 `sanguosha-community` 社区会话；返回始终保留 `gameAuthenticated:false`、`channelVerified:false`，直到有证据支持单独的游戏渠道认证。

| 本人私聊命令 | API 查询 kind | 接口与当前含义 | APP 协议 | 微信协议 |
| --- | --- | --- | --- | --- |
| `#三国个人资料` | `summary` | 本人游戏概览；此命令不等于社区 profile | 已接入，待实扫核对字段 | 已接入，待实扫核对字段 |
| `#三国战绩 [模式0-4]` | `records` | 本人战绩/胜率统计响应；0全部、1排位、2身份、3国战、4斗地主 | 已接入，待实扫 | 未接入该协议 |
| `#三国将力` | `force` | 本人将力接口响应 | 已接入，待实扫 | 未接入该协议 |
| `#三国资产` | `assets` | 本人 property 接口响应；具体余额/资产字段尚未验收 | 已接入，待实扫 | 未接入该协议 |
| `#三国皮肤` | `skins` | 本人 generalSkins 接口响应；拥有状态按官方字段核对 | 已接入，待实扫 | 未接入该协议 |
| `#三国武将收藏` | `favorites` | 社区 `general/getMyLike` 收藏列表，不能当作拥有武将列表 | 已接入，待实扫 | 未接入该协议 |
| `#三国能力` | `abilities` | 本人能力接口响应 | 已接入，待实扫 | 未接入该协议 |
| `#三国擅长武将` | `bestGeneral` | 本人擅长武将接口响应 | 已接入，待实扫 | 未接入该协议 |
| `#三国游戏资料` | `gameInfo` | 本人 gameInfo 接口响应 | 已接入，待实扫 | 未接入该协议 |

默认APP扫码和11类本人接口已在部署服务器验证连通性，具体字段与APP的完整逐项对照仍待完成，详见 [本次验收](VERIFICATION.md)。以上返回过滤后的真实 JSON 与来源，不填造未返回的字段。过长结果导出 JSON：云崽需要协议端支持好友文件发送，Bot 从内存发送，不写入插件持久目录；CLI直接输出JSON，二维码请用Bot获取。其他 QQ 无法通过命令参数选择你的会话；群内拒绝授权、个人查询和账户操作。

独立 `CommunityAuthClient.queryOwn()` 还提供以下已核实协议，当前没有对应 Bot 命令：APP 的 `profile`；微信的 `profile`、`roles`。已新增 `#三国近期战绩 [模式] [页码]`，`recent` 为最近对局列表，参数 `{model:0..4,page:1..1000}`；与当前 `#三国战绩` 的统计接口不同。`roles` 是官方其他游戏角色映射响应，不能据此自动宣称官号/华为渠道已认证。默认 APP 会话不调用新版专属端点，微信会话不调用旧版专属端点。

官方返回未关联角色（业务码 20020）时，在三国咸话 APP 内完成关联；插件没有编造关联协议。会话失效（HTTP 401/业务码 1003 等）会明确要求重新扫码。APP 二维码采用官方前端 120 秒轮询窗口，接口未给出精确服务端期限；微信二维码使用服务器 `expireIn`。二维码过期与会话过期分别处理，不虚构 APP 会话寿命。

## 配置参数

配置示例为 `config/example.json`；初始化产生 `config/local.json`。实例文件、加密会话、身份登记和导出均不提交 GitHub。数值需在下列范围内，修改后重启 Bot。

| 字段 | 默认值 | 实际作用 |
| --- | --- | --- |
| `enabled` | `true` | 启用命令处理；`false` 时不处理插件命令 |
| `adapter` | `"none"` | `none` 为 CLI/API；`yunzai` 注册 TRSS/云崽命令，修改需重启 |
| `prefix` | `"#三国"` | 命令前缀，长度 1–20 |
| `timeoutMs` | `12000` | 官方请求超时毫秒，1000–60000 |
| `cacheSeconds` | `300` | 公开资料缓存秒数，60–3600；本人资料不使用此缓存 |
| `maxReplyChars` | `3500` | 回复截断/本人 JSON 转文件阈值，500–8000；公共格式器另有内部长度上限 |
| `maxItems` | `8` | 部分公开列表的查询条目上限，1–20；武将/无关键词攻略还有各自默认上限 |
| `credentialsKey` | 初始化随机生成 | 64 位十六进制 AES-256-GCM 密钥；保留在实例中，不公开、不随意更换 |
| `channels.official` | `true` | 允许登记官号游戏身份，不是官号登录开关 |
| `channels.huawei` | `true` | 允许登记华为游戏身份，不是华为登录开关 |
| `masters` | `[]` | 保留字段；当前核心未用作授权控制。橙汁实例配置入口由其 `ownerOnly` 管理 |
| `officialSite` | `https://www.sanguosha.cn/` | 来源展示字段；请求使用代码内核验过的固定官方端点，不用此字段改写请求地址 |
| `communitySite` | `https://xh.sanguosha.cn/web/2` | 来源展示字段；同上 |
| `personalDataEnabled` | `true` | 社区授权与本人查询开关；`false` 停止开始授权、查询扫码状态和本人数据，仍允许退出已有授权；启用后仍需本人私聊、有效会话和具体协议支持 |

`credentialsKey` 与 `data/sessions.enc.json` 一起备份在私有位置。源码同步前检查 `.gitignore`；不要上传整个实例目录、导出 JSON、二维码或原始研究 HTML/JS。Linux 私密文件使用 0600 权限，Windows 仍需依靠所在目录的实际访问权限。

## 上线验收

以下是操作清单，**未勾选项目不表示已经完成**。`npm test` 验证模拟协议与隔离逻辑，不能替代真实官方连通性、扫码或 QQ 投递测试。

- [ ] Node 版本满足要求；在插件目录完成安装、初始化及 `npm test`，`node cli.mjs diagnose` 输出当前社区协议/游戏渠道状态。
- [ ] 云崽实例设为 `adapter: "yunzai"` 并重启，`#三国帮助` 正常显示，未与其他插件命令冲突。
- [ ] 从 Bot 所在服务器实际查询资讯、公告详情、武将 ID、攻略、模式、社区和四种热榜，核对移动版来源。网页解析测试通过不代表该服务器可连接官网。
- [ ] 启用实例 `personalDataEnabled` 后，私聊创建默认 APP 二维码；三国咸话 APP 能识别并完成官方确认，`#三国扫码状态` 先显示待扫码，确认后通过本人社区资料验证。
- [ ] 对每条本人查询与官方 APP 核对角色、模式及关键字段；未关联角色与失效会话有准确提示，无法读取项目按实际记录缺口。
- [ ] 第二个 QQ 不能读取第一个 QQ 的会话；群消息不能创建二维码、取本人资料、列账户或绑定身份。
- [ ] 私聊二维码图片正常送达；大 JSON 通过好友文件送达，或明确提示协议端不支持。CLI只输出数据，不自动保存明文私密文件。
- [ ] 退出授权后本地会话已删除；远程注销失败时仍能删除本地会话且提示准确，解绑游戏身份不会被误认作退出社区授权。
- [ ] Git 已跟踪文件中没有 `config/local.json`、`data/`、密钥、会话、二维码、QQ/游戏身份和原始研究文件。
- [ ] 对外发布说明仍标明官号/华为游戏渠道登录未验证，以及本人接口待实扫项目，避免用协议单元测试替代用户验收。

官方来源、端点和核验记录见 [API 审计](API-AUDIT.md) 与 [致谢](CREDITS.md)。
