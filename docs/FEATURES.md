# 功能、配置与上线检查

公开图鉴支持 `#sgs全部武将`、`#sgs吴国武将 [页]`（也支持魏、蜀、群、神），以及 `#sgs皮肤图鉴 [武将] [至尊/传说/原画] [页]`、`#sgs关羽皮肤`。武将每页24项，皮肤每页12项，均返回本地原生图片，群内可用且不需要登录。目录以移动版官网与官方皮肤绘影堂收录为准，不等同客户端全集或本人拥有；范围与来源见 [CATALOG.md](CATALOG.md)。

本人胜率命令为 `#sgs胜率 [模式]`、`#sgs势周瑜胜率排位`、`#sgs胜率 势周瑜 身份`；战绩首图也显示对应模式胜率。命令名称不变，受 `personalDataEnabled` 及当前会话协议支持范围控制；当前微信协议的战绩和胜率尚未接入验证。仍有效的旧会话可继续使用其已接入查询，群内只展示发送者自己的统计。总/分模式与近期统计分别标明范围，未返回武将不当作 0%。动态卡使用 AI-Plugin 共享原生渲染，安装依赖和统计口径见 [RENDERING.md](RENDERING.md)。

当前版本：0.1.0。仅支持三国杀移动版。此前旧版 APP 扫码与 11 类本人接口连通性已完成真实用户验收；当前统一用 `#sgs登录` 微信扫描官方新版二维码，旧扫码入口已移除。**旧版验收不证明当前微信协议支持全部查询；当前仅资料、概览和角色映射已接入协议，仍待本人实扫验收。官号与华为游戏渠道未接通。** 具体脱敏记录见 [本次验收](VERIFICATION.md)；每位用户仍需自己授权。

| `#sgs社区 [关键词]` | 最新公开帖子或关键词搜索 | 社区公开资料 |
| `#sgs热榜 [today或theme或week或all]` | 今日帖子、热门话题、一周红人、著名大佬 | 默认 today；后两项是社区人气排行，不是游戏战力/排位榜 |
| `#sgs登录` | 创建当前社区微信扫码请求并发送本地二维码；等待期间保留原有效授权 | 仅本人私聊；微信扫一扫官方二维码，不是游戏渠道登录 |
| `#sgs官号登录` | 返回游戏协议未接通状态及官方指引 | 仅本人私聊；不会启动社区扫码，查询本人资料须另用社区授权命令 |

| `#sgs扫码状态` | 查询当前微信扫码进度；严格验证本人 `userId` 后原子替换主会话，并删除旧会话和全部待扫码内容 | 仅本人私聊；失败、过期或待扫码不删除原有效授权，不消费旧 APP 待扫码请求 |
| `#sgs授权状态` | 查看本人本地已保存的授权协议与待扫码状态，不输出凭据 | 仅本人私聊；本地记录不等于实时验证令牌仍有效 |
| `#sgs取消授权` | 仅清除本人当前待扫码请求 | 仅本人私聊；保留原有效授权，不作为退出登录 |
| `#sgs退出授权` | 删除本人全部本地加密社区会话与待扫码请求 | 仅本人私聊；新版尝试远程注销，旧版远程撤销未核实；远程失败不阻止本地删除 |
| `#sgs绑定 官号或华为 游戏ID [区服]` | 按渠道分开加密登记本人游戏身份 | 仅本人私聊；未验证角色归属，不代表已登录或已关联社区角色 |
| `#sgs账户` | 查看本人登记的游戏身份 | 仅本人私聊；展示未认证状态 |
| `#sgs解绑 [官号或华为]` | 删除本人指定渠道身份；不带参数删除全部登记身份 | 仅本人私聊；社区会话独立，需另行退出授权 |

消息通常只显示摘要与原文链接。官网将池、概率、皮肤等图片可由独立 API 返回来源；当前 Bot 公开命令不自动 OCR，也不保证发送全部原图。分页、攻略详情等完整调用能力通过 `MobilePublicClient` 提供，当前命令表不含定时推送、签到或自动游戏操作。

## 本人查询命令与协议

`#sgs登录` 统一使用 `pc-scan-v7` 微信扫码；Bot 不再创建或继续旧 `app-qr-v1` 扫码请求，旧有效会话仅在切换成功前按原协议保留。成功建立的是 `sanguosha-community` 社区会话；返回始终保留 `gameAuthenticated:false`、`channelVerified:false`，直到有证据支持单独的游戏渠道认证。

新版二维码须通过微信在官方网页确认，不接收用户密码或 Cookie。新请求等待期间保留原有效会话；只有票据交换及新版本人 `userId` 校验成功，才原子替换主会话并删除旧会话、旧待扫码和新版待扫码内容。失败、过期或取消新版请求保留原有效会话。新版成功后不继续用旧令牌调用旧协议专属接口；不支持的查询明确提示限制。新版完整拥有列表尚未接入或本人实测，不能承诺扫码后取得全部武将、全部皮肤或全部 APP 信息。

| --- | --- | --- | --- | --- |

胜率命令另支持 `#sgs胜率 [模式]`、`#sgs势周瑜胜率 [模式]`、`#sgs胜率 势周瑜 [模式]` 和 `#sgs武将势周瑜胜率 [模式]`；模式可直接连写在“胜率”后，例如 `#sgs势周瑜胜率排位`。模式对应 `全部/0`、`排位/排位赛/1`、`身份/身份场/2`、`国战/3`、`斗地主/欢乐斗地主/4`。近20场查询传入同一个官方模式编号；指定武将模式时不会用其他模式或模式未标明的近期统计回填。

历史旧 APP 扫码和 11 类本人接口已在部署服务器验证连通性，具体字段与 APP 的完整逐项对照仍待完成。旧协议的 `summary/force/records/recent/assets/gameInfo` 按官方前端已核实的字段显示中文摘要，未知字段不猜含义；未映射的结构保留官方字段名。受当前协议支持的本人查询末尾可加 `导出` 获取完整已脱敏 JSON，例如 `#sgs资产 导出`、`#sgs战绩 2 导出`、`#sgs近期战绩 0 1 导出`。摘要限条不会删掉导出中的未知字段或其余数组项；字段证据与公式见 [PERSONAL-FIELDS.md](PERSONAL-FIELDS.md)。当前微信会话不套用旧 APP 字段映射。

Bot 个人文件通过内存 Buffer 发送，不创建插件明文临时文件；原始 JSON 超过 8 MiB 时在内存中 gzip 并发送 `.json.gz`，压缩后仍超过上传上限则拒绝。协议端须支持好友文件发送。CLI 只输出文本/JSON，不自动保存数据或二维码；二维码请去 Bot 私聊获取。其他 QQ 无法通过命令参数选择你的会话。

群内仅可展示发送者本人的胜率、战绩、近期战绩、将力、能力和擅长武将；群结果按游戏统计字段白名单投影，文字回退也不会自动附原始 JSON 或文件。资产、个人资料、游戏资料、皮肤、武将收藏、扫码授权/状态、退出授权、身份绑定/账户/解绑和所有完整导出仍仅本人私聊。群消息和参数校验先于 API 调用，群卡还须通过发送层的本人分享核验。

独立 `CommunityAuthClient.queryOwn()` 还提供当前没有对应 Bot 命令的旧协议 `profile`（历史线上已成功）及微信 `profile`、`roles`（尚待该协议授权验收）。`recent` 与 `#sgs战绩` 的统计接口不同；最近一页不代表完整历史。`roles` 是官方其他游戏角色映射响应，不能据此自动宣称官号/华为渠道已认证。保留的旧会话不调用新版专属端点，微信会话不调用旧版专属端点。

官方返回未关联角色（业务码 20020）时，在官方页面或 APP 内完成关联；插件没有编造关联协议。会话失效（HTTP 401/业务码 1003 等）会明确要求重新扫码。当前微信二维码使用服务器 `expireIn`；旧 APP 前端的 120 秒轮询窗口仅为历史协议记录，不再作为 Bot 扫码入口。二维码过期与会话过期分别处理，不虚构会话寿命。

## 配置参数

配置示例为 `config/example.json`；初始化产生 `config/local.json`。实例文件、加密会话与身份登记不提交 GitHub。个人 JSON/二维码不由 CLI 自动落盘，Bot 内存上传也不写插件明文临时文件。数值需在下列范围内，修改后重启 Bot。

| 字段 | 默认值 | 实际作用 |
| --- | --- | --- |
| `enabled` | `true` | 启用命令处理；`false` 时不处理插件命令 |
| `adapter` | `"none"` | `none` 为 CLI/API；`yunzai` 注册 TRSS/云崽命令，修改需重启 |
| `prefix` | `"#sgs"` | 命令前缀，长度 1–20 |
| `timeoutMs` | `12000` | 官方请求超时毫秒，1000–60000 |
| `cacheSeconds` | `300` | 公开资料缓存秒数，60–3600；本人资料不使用此缓存 |
| `maxReplyChars` | `3500` | 回复截断/本人摘要或原字段 JSON 转文件阈值，500–8000；公共格式器另有内部长度上限 |
| `maxItems` | `8` | 部分公开列表与本人数组摘要的条目上限，1–20；完整 JSON 导出保留接口层已读取的条目，武将/无关键词攻略还有各自默认上限 |
| `credentialsKey` | 初始化随机生成 | 64 位十六进制 AES-256-GCM 密钥；保留在实例中，不公开、不随意更换 |
| `channels.official` | `true` | 允许登记官号游戏身份，不是官号登录开关 |
| `channels.huawei` | `true` | 允许登记华为游戏身份，不是华为登录开关 |
| `masters` | `[]` | 保留字段；当前核心未用作授权控制。橙汁实例配置入口由其 `ownerOnly` 管理 |
| `officialSite` | `https://www.sanguosha.cn/` | 来源展示字段；请求使用代码内核验过的固定官方端点，不用此字段改写请求地址 |
| `communitySite` | `https://xh.sanguosha.cn/web/2` | 来源展示字段；同上 |
| `personalDataEnabled` | `true` | 社区授权与本人查询开关；`false` 停止开始授权、查询扫码状态和本人数据，仍允许退出已有授权；启用后仍需有效本人会话及协议支持，群内只允许上述统计项目 |

`credentialsKey` 与 `data/sessions.enc.json` 一起备份在私有位置。源码同步前检查 `.gitignore`；不要上传整个实例目录、导出 JSON、二维码或原始研究 HTML/JS。Linux 私密文件使用 0600 权限，Windows 仍需依靠所在目录的实际访问权限。

## 上线验收

以下是每个实例可重复使用的上线检查表，当前已确认和待确认结果分别列在 [VERIFICATION.md](VERIFICATION.md)。`npm test` 验证模拟协议与隔离逻辑，不能替代真实官方连通性、扫码或 QQ 文件投递测试。

- [ ] Node 版本满足要求；在插件目录完成安装、初始化及 `npm test`，`node cli.mjs diagnose` 输出当前社区协议/游戏渠道状态。
- [ ] 云崽实例设为 `adapter: "yunzai"` 并重启，`#sgs帮助` 正常显示，未与其他插件命令冲突。
- [ ] 从 Bot 所在服务器实际查询资讯、公告详情、武将 ID、攻略、模式、社区和四种热榜，核对移动版来源。网页解析测试通过不代表该服务器可连接官网。
- [x] 历史旧 APP 扫码已由真实用户完成，官方本人资料验证成功，session AES 保存；旧扫码入口现已移除，不将历史结果视作当前微信验收。
- [ ] 使用原命令 `#sgs登录`、`#sgs扫码状态` 完成微信扫码，官方本人 `userId` 严格验证通过；新会话主记录、旧会话和全部待扫码内容在一次加密写入中完成替换与清理，不能长期并存。
- [ ] 新版待扫码、过期、失败和取消保留原有效会话；不能让旧 APP 令牌用于新版接口，也不能将旧 `id` 视作新版 `userId`。
- [ ] 对每条本人查询与官方 APP 核对角色、模式及关键字段；未关联角色与失效会话有准确提示，无法读取项目按实际记录缺口。
